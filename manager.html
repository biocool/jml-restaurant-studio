Map evidence & privacy

Coordinates were calculated once from the bundled public business addresses by the US Census Geocoder. Its coordinates are interpolated along street address ranges. They do not independently confirm a restaurant’s entrance, operating status or suite.

Changed or newly added addresses are not sent for geocoding and do not receive automatic pins. Stale pins are withheld. Names, notes and address edits stay in your browser. Opening this map loads OpenStreetMap tiles for the viewed region; the tile server receives ordinary IP/referrer and map-area requests, not your record fields. Disable Street map to use only local pins.

Clusters represent only this collection, not all restaurants or market demand. Filters and city totals include records lacking pins. Geocoding source records · Report a street-map issue

PORTABLE BY DESIGN

Your data. In your hands.

Back up before you go.

Edits stay in this browser. They do not automatically update GitHub or sync to another device.

JSON preserves all fields and uploaded photos. CSV keeps full records in its _record_json column. Publishing is a separate manual step. Keep confidential notes out of public exports.

Evidence, not assumptions.

Research candidates are not completed Google audits. Latest expansion scope and limitations. Price labels, photo identity and source confidence retain their original caveats inside each record. Blank gauges remain unknown until entered.

Saved on this device only · Export JSON regularly · No automatic GitHub sync

Your browser is the workspace.

Autosave uses IndexedDB, with localStorage fallback. Storage is tied to this browser and origin. Private browsing, clearing site data or moving to another browser can remove it.

Backup JSON preserves everything, including uploaded photographs. CSV preserves full records in _record_json plus editable columns. Export website ZIP generates all current flyers and audits.

GitHub: upload this project manually, then replace data/records.js using “Export GitHub data.js” when ready to commit changes. This app has no GitHub credentials or API sync. Existing browser edits override repository seed data until you import or reset them.

GitHub Pages is static hosting, not private storage. Do not publish confidential notes or unlicensed photos. Nothing has been published by this app.
